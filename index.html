sun4v-qemu-kit

sun4v-qemu-kit is a complete firmware build kit for QEMU's emulated UltraSPARC T1 machine (-M niagara), based on files from the OpenSPARC Project.

It builds all six files QEMU loads, in four parts:

  • OpenBoot PROM (OBP): openboot.bin (Sun's Forth-based Open Firmware)
  • Hypervisor (hv): q.bin + reset.bin (the layer under sun4v-series LDoms)
  • Machine descriptions (MD): a set of directed acyclic graphs, compiled to binary
    • 1up-hv.bin (the whole platform description, for hv)
    • 1up-md.bin (the guest's description, for OBP and OS)
  • Empty NVRAM stub: nvram1

Solaris 10 1/13, from the ISO to the installer, on QEMU master (11.1.50). Idle time is shortened.

Why

QEMU's niagara machine loads the firmware files listed above as opaque binaries, and the sets published so far were fixed, prebuilt blobs. Sun had published the source of all of them (OpenSPARC T1 and T2, 2006–2009), and the design records survive as FWARC case files in the sun4v archive.

What was missing was a way for QEMU users to build working firmware from it.

Challenges

  • Unexplored format for 1up-hv.bin and 1up-md.bin.
  • Building the hypervisor blind.
  • Forth-on-SPARC that builds itself: a five-step bootstrap chain.
  • A SPARC platform that builds its own firmware: a PCIe-capable niagara machine in QEMU.

Build flows

  • OpenBoot build flow: openboot.bin is the result of a bootstrap chain of Forth dictionaries, from 32-bit to 64-bit, built on the Sun and the GNU path.
  • OpenSPARC T1 hypervisor build flow: q.bin + reset.bin, on the Sun and the GNU path. The four routes at the top make the same offsets.h; the assembler cannot tell which was used.

What is shown

  • The latest Solaris 10 for SPARC, 1/13, boots to its installer on QEMU's emulated sun4v machine with sun4v-qemu-kit firmware.
  • Builds. Cross-builds on Linux (or in containers), or native builds on Solaris; see the build matrix.
  • A test suite in tests/, which runs even on a stock QEMU.
  • Sun's source is untouched. The build applies patches to a copy of src/, never to the files themselves.

Getting Started

You need QEMU as the distribution packages it, the kit's build requirements (REQUIREMENTS.LINUX or REQUIREMENTS.SOLARIS), and for the login test a Solaris 10 disk image: the T1 archive from Oracle contains one (S10image/disk.s10hw2, see Credits). The steps are in README.USAGE in the repository.

Limitations

  • Only the single-strand configuration is built and supported.
  • With more than 1024 MB of RAM the stock Solaris 10 1/13 DVD uses 256M pages, which stock QEMU does not decode correctly; that needs a QEMU patch.
  • The pci configuration runs only on a QEMU with experimental patches, not included in this kit; getting them into QEMU is currently held up by its AI policy (details).
